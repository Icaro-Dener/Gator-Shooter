# Gator Shooter

Jogo top-down em pixel art feito em HTML5 Canvas puro, num único arquivo, sem dependências nem build.

## Como jogar

Abra `index.html` no navegador.

| Controle | Ação |
|---|---|
| WASD | mover |
| Mouse | mirar |
| Clique esquerdo | atirar (shotgun) |
| M | liga/desliga o som |
| R | recomeçar após o game over |
| ESC | voltar ao menu |

## Modos

- **Campo de teste**: um inimigo parado (que reaparece) e uma caixa de munição, para testar o tiro.
- **Roguelike**: defenda a casa no centro. Os jacarés vêm das bordas, cada vez com mais frequência, e mordem a casa. Se a vida dela chegar a zero, você perde.

## Arquivos

Todos os sprites estão embutidos em `index.html` (base64). Os `.png` da pasta são as cópias originais, para referência e edição.
